# Development Tools

Helper scripts for local testing and debugging (not required to run the mod).

- `virtual_p2.py`: Emulates a virtual Xbox 360 Player 2 controller via ViGEmBus + `vgamepad` so dual-player split-screen can be tested on a single keyboard (`F7`/`F8`, Numpad, or `IJKL`). See [docs/dev/teclado-como-segundo-controle.md](../docs/dev/teclado-como-segundo-controle.md) for background notes.
